# Protótipo original

`partitura-bdo.html` foi o rascunho de uma página só usado para validar a ideia antes de virar o app em `src/`. Fica aqui como referência histórica — a lógica dele (parser de MIDI, quantização, catálogo de instrumentos) já foi migrada e refinada em `src/lib/`.

Não é mais mantido. Para rodar o projeto, use a raiz do repositório (`npm install && npm run dev`).
